# אוולין הולכת

שיעורי תכנות לאוולין, בעברית, לטלפון.

השיעורים לפי תוכנית Animated Genres של ScratchJr
(DevTech בטאפטס ו-Lifelong Kindergarten ב-MIT Media Lab), גילאי 5–7.

- שיעור 1: הוראות. בלוק בשורה, לחיצה על הבלוק מזיזה. ימינה, שמאלה, למעלה, למטה.
- שיעור 2: סדר. אותו בלוק כמה פעמים, עד הכוכב. בלוק בית מחזיר להתחלה.

הציורים מקוריים. לא מעתיקים את הדמויות או את הבלוקים של ScratchJr.
