# ScratchJr · אוולין

שיעורי תכנות בעברית לטלפון, לפי תוכנית Animated Genres של ScratchJr
(DevTech בטאפטס ו-Lifelong Kindergarten ב-MIT Media Lab).

## הסדרה המלאה

### מודול 1 · קולאז׳
1. הוראות — בלוק אחד מזיז
2. סדר — כמה בלוקים עד מטרה
3. דגל ירוק וסוף
4. רקע ושתי דמויות

### מודול 2 · סיפור
5. מהירות
6. מספרים על בלוקים וחזרה
7. דיבור, צליל, חכה, עמוד

### מודול 3 · משחק
8. נגיעה, התנגשות, הודעות, עצור

הרשת כמו ב־ScratchJr: 20×15 משבצות. צעד אחד = משבצת אחת (מקס׳ 20 אופקי / 15 אנכי).

לחיצה על מספר הבלוק מעלה את מספר הצעדים. ⌫ מנקה את השורה. דגל ירוק מפעיל.
